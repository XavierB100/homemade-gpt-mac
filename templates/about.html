🧠 VV-GPT Theory & Architecture

An extensive educational breakdown of the mathematics, theory, and precise codebase mechanics that drive the VV-GPT language model.

1. The Theory: What is a Transformer?

Since the groundbreaking 2017 paper "Attention Is All You Need" by Vaswani et al., the Natural Language Processing world shifted away from Recurrent Neural Networks (RNNs) and Long Short-Term Memory (LSTMs) towards the Transformer sequence-to-sequence architecture.

VV-GPT is based strictly on the Decoder-only subset of the original Transformer architecture. This is identical to the underlying architecture of OpenAI's GPT-1, GPT-2, and GPT-3.

Core Theoretical Concepts:
  • Auto-Regressive Generation: The model generates text one token at a time. It uses the previously predicted token as part of the context to predict the next token. This is repeated to generate full paragraphs.
  • Character-Level Tokenization: While modern LLMs use Subword (BPE) tokenization, this version of VV-GPT uses character-level tokens to remain highly educational. Every alphabetical letter, space, and emoji is mapped to a unique integer ID.
  • The "Context Window": Neural networks cannot process text directly. Text is converted to numbers. The sequence of numbers is restricted to a absolute length (in our case, `block_size` usually 256 or 512). The neural network analyzes the previous 256 characters collectively to guess the 257th.

2. The Mathematics of Attention

The beating heart of VV-GPT is the Self-Attention Mechanism. Rather than reading a sentence left-to-right, Attention allows every character in the sequence to look at every other character in the sequence mathematically simultaneously to determine context.

The Query, Key, and Value (QKV)

For every token embedding vector \( x_i \), we project it through three separate linear transformation matrices to create three new vectors:

  • Query (\( Q \)): "What information am I looking for?"
  • Key (\( K \)): "What information do I contain?"
  • Value (\( V \)): "If you find my key relevant, here is the actual content you should extract."
Scaled Dot-Product Attention

We calculate the "affinity" or "attention score" between token \(A\) and token \(B\) by taking the dot product of \(A\)'s Query and \(B\)'s Key. The higher the dot product, the more they relate. We scale this down by the square root of the embedding dimension (\( \sqrt{d_k} \)) to keep gradients stable, and apply a Softmax function to turn the scores into probabilities (0 to 1) that sum to 1. Finally, we multiply these probabilities by the Values (\( V \)).

\[ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V \]
Causal Masking

Because VV-GPT is a generative model, it is strictly forbidden from "looking into the future" during training. If we are trying to predict the 5th character, the 5th character's Query can only calculate dot products with Keys from positions 1, 2, 3, and 4. We enforce this mathematically using a lower-triangular matrix filled with \(-\infty\) (negative infinity) above the diagonal. When the Softmax is applied, \(-\infty\) becomes 0.

\[ \text{Mask}(i, j) = \begin{cases} 0 & \text{if } i \geq j \\ -\infty & \text{if } i < j \end{cases} \]
Pre-Layer Normalization

Unlike the original 2017 Transformer which Normalized after the residual connection (Post-Norm), VV-GPT uses the GPT-2 innovation of Pre-Norm. We apply Layer Normalization before the Attention and before the Feed-Forward Network. This makes deep networks massively more mathematically stable during backpropagation.

\[ x_{out} = x + \text{Attention}(\text{LayerNorm}(x)) \] \[ x_{final} = x_{out} + \text{MLP}(\text{LayerNorm}(x_{out})) \]

3. The Training Loop

Training the model is the process of altering the weights of the network (the matrices that create Q, K, V, and the MLP layers) so that the network minimizes errors in its predictions.

  1. Batching: We pull a random chunk of text (e.g. 64 sequences, each 256 characters long).
  2. Forward Pass: The network guesses the very next character for every single position in that 256-length window across all 64 sequences.
  3. Cross-Entropy Loss: We measure how wrong the network was. It output a probability distribution over the ~60 character vocabulary. Did it assign 99% to 'e' when the answer was actually 'e'? Good. Did it assign 1% to 'e'? Bad (High Loss).
  4. Backpropagation: We use PyTorch's Autograd engine to calculate the gradient of the loss with respect to every single parameter in the model. This tells us which direction to nudge the weights.
  5. AdamW Optimizer & Weight Decay: We use the AdamW algorithm to update the weights. Weight decay actively shrinks parameters towards zero, ensuring the network doesn't rely entirely on a few massive weights to memorize the text (overfitting).
  6. Cosine Learning Rate Decay: We start with a high learning rate to learn general patterns quickly, then smoothly cosine-decay the rate down to fine-tune the final details.
